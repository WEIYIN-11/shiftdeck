## A. 核心三項（只有 15 分鐘就做這些）

這三項任何一項不過，該階段就要退回重做。

### A1 ⭐ 原生可編輯性 — 產品的立身之本

**開啟** `verify\pagetypes_四個頁型.pptx`

| 檢查 | 通過的樣子 |
|---|---|
| 點一下方框 | 出現八個控制點，可拖曳縮放 |
| 點一下箭頭 | 是獨立可選取的圖形，不是圖片的一部分 |
| 雙擊文字 | 游標進入，可以直接打字修改 |
| 右鍵任一元素 → 設定圖形格式 | 有填滿／線條選項（證明是原生 DrawingML） |

❌ **不通過的樣子**：整頁只能選到一張大圖、文字選不起來、右鍵只有「設定圖片格式」

> 這條若失敗，等於 shiftdeck 退化成一般 AI 簡報工具，整個產品定位不成立。

### A2 ⭐ 動畫零回歸 — 不可傷害既有行為

**開啟** `verify\stage3_none.pptx`（這是對照組）

1. 切到「動畫」索引標籤 → 開啟「動畫窗格」
2. **動畫窗格應該完全是空的**
3. 切到「切換」索引標籤 → 每頁應該是「淡出」（fade）

❌ 不通過：動畫窗格有任何項目 → 表示沒選動畫時也被塞了東西，這是回歸

### A3 ⭐ 繁中介面不爆版

在剛開的確認頁上：

1. 右上角語言切換 → 應該看得到「**繁體中文**」
2. 選下去，整頁應該變繁體
3. **重點看**：語言按鈕本身會不會被「繁體中文」四個字撐爆、下拉選單有沒有跑版
4. 切回「中文」「English」「日本語」→ 應該都正常

❌ 不通過：選項不存在、切換後有區塊沒變、按鈕文字被截斷或溢出

## B. 繁體中文（約 10 分鐘）

承 A3 的畫面繼續往下捲。

- [ ] **B1 字型下拉**：找到字型選擇區，應顯示 `微軟雅黑 · Microsoft YaHei` 這種「中文名 · 英文 id」格式。**英文 id 必須看得到**（那是實際寫進檔案的識別碼，翻掉會壞掉）
- [ ] **B2 視覺風格卡片**：18 種風格的繁中描述，看有沒有斷行怪異、文字擠出卡片
- [ ] **B3 用詞順不順**：重點看這幾個是否符合你的職場習慣——「範本」（不是模板）、「投影片」（不是幻燈片）、「套用」（不是應用）、「字級」（不是字號）。**有任何一個你覺得台灣人不這樣講，直接告訴我**
- [ ] **B4 預覽編輯器也要繁中**：另開終端機跑
  ```bash
  python skills/ppt-master/scripts/svg_editor/server.py projects/verify_ui_ppt169_20260812 --live --daemon
  ```
  切成繁中後，點選面板、標註列表這些**動態區塊**是否也跟著變（靜態文字容易對，動態的才是考驗）
- [ ] **B5 自動偵測語系**：瀏覽器按 F12 → Console 貼 `localStorage.removeItem("ppt_lang")` → 重新整理 → 應該自動選繁體中文

## C. 頁型庫（約 5 分鐘）

**開啟** `verify\pagetypes_四個頁型.pptx`，四頁分別是對比／SWOT／KPI／流程圖。

- [ ] **C1 版面觀感**：四個版型你會不會實際拿來用？擠不擠、留白夠不夠
- [ ] **C2 對比頁的設計取捨**：我讓它做成「面向欄＋A欄＋B欄」的列帶式，而不是左右兩張獨立卡片——理由是避免「價格／導入時間／風險」這些面向名重複寫兩遍。**這個取捨你同不同意？**
- [ ] **C3 SWOT 的正負編碼**：正面（S/O）用面板色、負面（W/T）用頁底色來區分，沒有用紅綠對比色（規範不准顏色單獨承載必要區分）。**這樣夠不夠一眼看懂？**

> 尚未驗證：流程圖 5 個與 6 個節點的排法（3／4／7 已驗過）。首次實際用到時看一眼即可。

## D. 動畫（約 10 分鐘）

- [ ] **D1 三套組的實際觀感**：依序開啟並播放
  | 檔案 | 應該是什麼感覺 |
  |---|---|
  | `stage3_professional.pptx` | 沉穩：純淡入、頁間淡出、不搶戲 |
  | `stage3_lively.pptx` | 活潑：飛入＋縮放、頁間推移、有節奏 |
  | `stage3_minimal.pptx` | 極簡：頁內完全不動，只有頁間淡出 |

  按 F5 全螢幕播放，**用觀眾的眼睛看**：專業那套會不會太悶？活潑那套會不會太吵？

- [ ] **D2 方向感一致性**（這項我特別想請你確認）：`entrance_fly` 的「上」是**從上方飛進來**，`entrance_wipe` 的「上」是**往上擦除**——兩者語意相反卻共用同一組方向標籤。開 `stage3_lively.pptx` 看飛入動畫，判斷這個標籤會不會讓人選錯

- [ ] **D3 動畫面板版面**：在預覽編輯器裡點一個元素，右側動畫面板有 2 個下拉＋2 個按鈕，繁中標籤比英文長——**擠不擠？**

> 已知限制（不必驗，知道就好）：`entrance_split` 在瀏覽器預覽裡是單一動作，匯出的 PPTX 才是正確的兩段式揭示。預覽是近似。
