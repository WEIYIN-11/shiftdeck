# shiftdeck 使用說明

寫給要做簡報的人，不是寫給工程師。指令都可以直接複製貼上。

全程你只會做四件事：**裝一次 → 在對話裡講你要什麼 → 在瀏覽器裡按幾下 → 拿到 .pptx**。

---

## 你需要先有什麼

| 東西 | 為什麼 | 哪裡拿 |
|---|---|---|
| **Python 3.10 以上** | 引擎是 Python 寫的 | [python.org](https://www.python.org/downloads/)。Windows 安裝時**務必勾選 Add Python to PATH** |
| **Git** | 下載引擎用 | [git-scm.com](https://git-scm.com/downloads) |
| **一個會操作檔案的 AI 工具** | 它才是實際幹活的人 | Claude Code、Cursor、Codex CLI 等。你只會用到它的對話框 |
| LibreOffice（選配，建議裝） | 檢查成品有沒有跑版 | [libreoffice.org](https://www.libreoffice.org/) |

沒有 PowerPoint 也能用。做出來的是標準 `.pptx`，LibreOffice、Google Slides、Keynote 都開得起來。

---

## 一、安裝（只做一次）

開一個終端機（Windows 用 PowerShell），貼這三行：

```bash
git clone https://github.com/Coolkidlab-Yin/shiftdeck.git
cd shiftdeck
python scripts/setup.py
```

會下載 14,000 多個檔案，依網速大約要幾分鐘。跑完看到「覆蓋層套用 N 項」就算成功。

想確認裝好了沒：

```bash
python scripts/setup.py --check
```

看到「引擎狀態　就緒且版本相符」就對了。

> **為什麼下載這麼久？** shiftdeck 本身只有幾百 KB，它是「加在別人引擎上的一層」。引擎（ppt-master）不放在這個 repo 裡，安裝時才去抓，所以你永遠拿到的是鎖定過的那一版。

---

## 二、第一句指令

**用你的 AI 工具打開 `shiftdeck` 這整個資料夾**（不是裡面的子資料夾）。

然後在對話框貼上這種話——有材料就給路徑：

```
用 shiftdeck 做一份簡報。
材料：C:\Users\你的名字\Desktop\Q3業績報告.pdf
給主管看的季度檢討，12 頁以內，繁體中文。
```

沒材料、只有主題也可以：

```
用 shiftdeck 做一份簡報，主題是「2026 年 AI 工具導入評估」。
聽眾是不懂技術的部門主管，10 頁，繁體中文，語氣正式一點。
```

材料放哪都可以（桌面、下載資料夾都行），把路徑講給 AI 就好——它會**複製**一份進專案，不會動你的原檔。

### 接下來會發生四件事

| 順序 | 你會看到 | 你要做什麼 |
|---|---|---|
| 1 | 瀏覽器自動跳出**確認頁** | 選視覺風格、頁數、**動畫套組**，按確認。這裡會停下來等你 |
| 2 | AI 開始一頁一頁畫 | 等。可以去泡咖啡 |
| 3 | 另一個瀏覽器分頁：**預覽編輯器** | 邊畫邊看。想改動畫、換頁型就在這裡點 |
| 4 | 匯出完成 | 檔案在 `projects/<你的專案>/exports/` |

> **確認頁會停下來等你按**，不按它不會自己往下跑。這是刻意的——版面和動畫的決定權在你手上。

---

## 三、四個頁型怎麼用

頁型＝**版面的固定骨架**。不用跟 AI 描述「左邊放優點右邊放缺點」，直接挑一個。

| 頁型 | 什麼時候用 | 能放多少 |
|---|---|---|
| **對比頁** | 兩個方案 PK，逐條對照 | 3–5 個比較面向 |
| **SWOT** | 內外部條件盤點，好壞一起講 | 固定 4 象限 |
| **KPI 儀表板** | 一頁講清楚幾個關鍵數字 | 3–6 個指標 |
| **流程圖** | 有先後順序的步驟，每步有負責人或產出 | 3–7 個節點 |

### 兩種指定方式

**A. 生成前用講的**——在第一句指令裡直接說：

```
第 3 頁用 SWOT，第 5 頁用 KPI 儀表板放四個指標。
```

**B. 生成後用挑的**（這是 shiftdeck 的重點）——簡報已經做出來了，某一頁版面不喜歡：

1. 在**預覽編輯器**裡點開那一頁
2. 右邊欄找到「頁型」→ 按「換頁型」
3. 會展開四張縮圖，挑一張（也可以選「維持現有版面」，代表只要重畫不要換版）
4. 按「請 AI 重畫這一頁」
5. 畫面會顯示「請求已存好」——**這時回到對話框**，跟 AI 說：

```
重畫這一頁
```

AI 會讀取你的選擇，**只重畫那一頁**，其他頁一個字都不會動。

> 內容不會憑空生出來——它會拿那一頁原本的內容，重新填進新版面。

## 四、動畫套組怎麼選

在**確認頁**選一次，整份簡報就套用了，**不用再下任何指令**。

| 套組 | 看起來像什麼 | 什麼場合 |
|---|---|---|
| **專業沉穩** | 以淡入為主，動作短、不搶戲 | 對外提案、給客戶或老闆看 |
| **輕快活潑** | 適度飛入與縮放，重點逐項出現 | 內訓、分享會，你要靠節奏帶著講 |
| **極簡無干擾** | 只有換頁效果，頁面裡完全不動 | 資料密集、給人「讀」而不是「看你演」 |

不想要動畫就選「不加動畫」，匯出的檔案動畫窗格會是全空的。

### 想微調單一元素

在**預覽編輯器**裡點任何一個元素（標題、卡片、圖表），右邊會出現動畫面板：

- 換效果（每一類只放 6–8 個常用的，不會給你 200 個選項的災難）
- 調順序、調方向
- **按預覽可以只播這一個元素**——PowerPoint 必須整頁播完才看得到，這裡不用

### 存成自己的套組

改到滿意之後，在動畫面板的「套組另存」填一個名字存起來。之後這個套組會出現在確認頁的清單裡，標著「（自訂）」。檔案在 `overlay/animations/user/`，要不要納入版控由你決定。

> **老實說的邊界**：目前「專業沉穩」與「輕快活潑」在 LibreOffice 上放出來的差異沒有預期中大，「極簡無干擾」則是刻意頁內完全不動。套組的重新設計還在規劃中，目前這三個是可用但保守的版本。

## 五、只重做一頁

這是 shiftdeck 存在的主要理由：**改一頁不用等整份重跑**。

完整流程就是上面第三節的 B：預覽編輯器裡選 → 送出請求 → 回對話說「重畫這一頁」。

### 實際省下多少

實測 4 頁的專案：全部重跑 267 秒，只重做一頁 70 秒（**26%**）。

省下來的幾乎全部是「AI 重畫」的時間——機械處理（檢查、打包、匯出）反而多花了不到一秒，因為匯出永遠是全份的（引擎的釋出閘門要求整份檢查過才准匯出，這條繞不過去，也不該繞）。

頁面裡有圖片的專案差距更明顯：20 頁每頁一張大圖，打包全量 3.0 秒 vs 增量 0.77 秒。

### 想自己下指令也行

不透過預覽編輯器，直接在終端機：

```bash
python overlay/regen/regen_page.py projects/<你的專案> --show
```

會告訴你現在待處理的是哪一頁、要換成什麼頁型。AI 重寫完那一頁的 SVG 之後：

```bash
python overlay/regen/regen_page.py projects/<你的專案> --request
```

## 六、檢查成品有沒有跑版

**建議每次匯出都跑一次。** 這道檢查是被真實的坑逼出來的——程式的幾何檢查說「0 個錯誤」，人一開檔案就看到文字撐出方框。

```bash
python scripts/visual_check.py projects/<你的專案>/exports/<檔名>.pptx
```

它會用 LibreOffice 真的把每一頁渲染成 PNG，放在 `<檔名>_render/` 資料夾裡。點開來一頁一頁看：

- 文字有沒有撐出方框
- 換行有沒有斷在奇怪的地方
- 元素有沒有重疊、有沒有貼邊

LibreOffice 對字型寬度的估算比 PowerPoint 嚴格，在它上面乾淨，在別的軟體通常也乾淨。

## 七、卡住的時候

**看不到繁體中文**
確認頁和預覽編輯器的右上角有語言選單，選「繁體中文」。第一次用如果你的瀏覽器語系是 zh-TW，應該會自動選好。

**選了動畫套組，但匯出的檔案沒動畫**
先確認你是在**確認頁**選的（不是只在編輯器裡點過）。套組會在匯出時自動展開，不需要你手動跑任何指令。要驗證的話，用 PowerPoint 或 LibreOffice 開檔，看「動畫窗格」有沒有列出項目。

**`visual_check.py` 說找不到 LibreOffice**
要另外安裝，[libreoffice.org](https://www.libreoffice.org/) 下載預設安裝即可。不裝也不影響做簡報，只是少一道檢查。

**我的簡報檔案會不會被更新洗掉**
不會，只要專案是建在 `shiftdeck/projects/` 底下（預設就是）。`vendor/` 是引擎，重裝時會整個刪掉重抓——**永遠不要把自己的東西放進 `vendor/`**。

**瀏覽器沒有自動跳出來**
確認頁與預覽編輯器預設從 5050 埠開始找空的埠。網址會印在對話裡，也可以看 `projects/<專案>/live_preview/lock.json`。

**引擎想升級到新版**
改 `engine.lock` 裡的 `tag` 與 `commit`，再跑一次 `python scripts/setup.py`。如果引擎改動太大導致修補套不上去，安裝會直接停下來報錯，不會裝出一個壞掉的環境。

**想從頭再來一次**
把 `projects/<專案>` 整個資料夾刪掉就好，不會影響任何其他東西。

## 你的東西放在哪

```
shiftdeck/
├── projects/          ← 你的簡報都在這裡（不進版控）
│   └── 我的專案_ppt169_20260812/
│       ├── sources/       你給的材料（複製進來的）
│       ├── svg_output/    AI 畫的每一頁
│       ├── svg_final/     打包好的預覽
│       ├── exports/       ★ 最終的 .pptx 在這裡
│       └── live_preview/  預覽編輯器的狀態檔
├── overlay/animations/user/   ← 你存的自訂動畫套組
└── vendor/            ← 引擎，別放東西進去
```
